## Bench evidence (H2, the only perf change)

`BenchmarkPausedRunRebuild` (memory log; 5-stage def, recorded deltas,
trailing checkpoint — the exact paused-run rebuild shape):

| Shape | walk | snapshot | delta |
| :--- | :--- | :--- | :--- |
| 100 entries | 180.0µs | 14.9µs | **12.1×** |
| 1000 entries | 2.052ms | 126.0µs | **16.3×** |

The walk numbers match the 20261003 final-gate rebuild numbers within
noise (the gate-miss path IS the walk, byte-identical). Rebuild remains
linear on the walk path — snapshots accelerate exactly the
currently-paused-run case (the restart-durability hot path), which was
the honest scope set in the plan.

## Bugs found and fixed during execution (the gate doing its job)

1. **H1.2 deadlock**: the first version of the restart drift gate ran
   `tagRunMetaDrift` (takes `rt.mu`) inside `bindPendingPauses`' lock —
   caught immediately by `TestRestartRearmDriftRequireSameStaysPending`
   hanging; restructured match/check/consume into three phases.
2. **H1.2 destructive refusal**: `Resume` deletes the paused entry before
   the gate, so a refused resume destroyed the pause — the test caught
   it; refusal now restores the entry and the pending stage.
3. **H2.2 stamping gap**: `handlePause` appends the checkpoint entry via
   a direct `actionLog.Append` (bypassing `appendLog`), so checkpoints
   shipped hashless until stamped there by hand — caught by the restart
   parity test.
4. **H5 re-parent invariant**: `Register`'s C5 queue re-parenting copied
   queued events without their receipt stamps → bounds panic under race;
   stamps now re-parent with the events.
5. **H2.2-anansi**: anansi's `FindByID` panics on missing records — the
   snapshot load uses a query read and the save uses delete-then-create.
